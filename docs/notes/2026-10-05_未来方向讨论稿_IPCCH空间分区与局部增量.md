# 2026-10-05 未来方向讨论稿：IPCCH 空间分区与可迁移的局部增量

本文整理与 Fable 5.1（`claude-fable-5-1`）的对抗性讨论、已保存模型探针及两轮敏感性实验。性质是研究讨论，尚非执行 spec；K-means、地区交换和残差扫描均未实施。正式结果与两轮敏感性表格见 [组会报告](2026-10-04_组会讨论稿_IPCCH人口份额与GeoXGB.md)。

**当前问题是：开发期找到的局部增益，为什么没有变成滚动预测中的地理增益？证据既不支持“局部模型没有信号可学”，也尚不能确认“分区学错了”。后续分区方案需要同时回答区域内预测是否改善、部署时是否有足够支持采用局部模型。**

## 一、哪些判断已经修正，哪些仍然开放？

| 讨论中的判断 | 已核对的证据与结论边界 |
| --- | --- |
| 全局已拟合 F，残差均值近零，所以 F-only 局部没有可学信号 | 撤回。335/413 个子模型降低 S 上原始 q3 MSE；均值零也不排除条件信号。 |
| F 是 2014–2018，S 是 2019–2022，因而主要扫描到时间漂移 | 统一日历切分的描述错误。F/S 在跨地区汇总后共享 40 个月，F 中 47.47% 来自 2019–2022。但每个地区自己的 S 都晚于 F；漂移占比仍未检验，不能说漂移不存在或已降为次要因素。 |
| Stage1 只改善份额，解码吞掉增益，因此扫描不是瓶颈 | 撤回。32 套根层候选在相同 S 键上同时改善 MSE 和投影后的危机 F1。先前把 Stage3 拒绝计数当作 Stage1 是记账错误。 |
| 训练支持越大，局部必然越好 | 未识别。跨区域分箱受到区域身份、类别构成混杂；同区域支持变化通常较窄，不能证明样本量无关。 |
| 残差扫描与 XGB 分裂分数相同，所以搜索方法相同或一定无用 | 不成立。分数的代数形式相同不等于候选空间相同；其迁移收益尚未验证。 |
| 只增加历史或延长 Stage1 就能恢复空间增益 | 两轮已完成的敏感性检查均未支持；结论限于各自配置、日期和评估方法。 |

Geo 相对 persistence 的 q3 R² 改善不能用来解释 Geo 相对 pooled 的空间贡献。前者比较整个回归系统，后者才衡量本实验地理层的增量。以下分别保留开发 S、Stage3 历史验证和当前预测的分母。

## 二、开发 S 上确有局部信号，但不是独立迁移证据

只读探针核对了原运行的 16 个 q3 全局根和 413 个 q3 局部模型的哈希与拟合行。令 `r = y − global`、`d = local − global`，则：

`MSE(global) − MSE(local) = 2 mean(d × r) − mean(d²)`。

全部 826 组 F/S 恒等式核对通过。413 个子模型中，335 个在 S 上降低原始 q3 MSE，371 个的中心化 `cov(d,r)` 为正；F/S 区域平均残差异号的 198 个模型中，仍有 126 个改善。因此，“平均残差同号”不是局部树学习有效的通用必要条件。所有子模型的相对 MSE 改善中位数为 4.15%，不能仅凭改善模型的数量判断效应大小。

更直接的根层核对使用 **32 套候选、每套相同的 9,558 个 S 键**：两侧子模型组合相对各自全局根，全部同时改善原始 q3 MSE 和投影解码后的危机 F1；ΔF1 最小/中位/最大为 **0.00414 / 0.01145 / 0.01967**。全部 Stage1 节点决策为 151 接受、74 因无严格增益拒绝、57 无合格子区域。

这说明现有扫描与 F-only 局部增量在开发期能找到有效修正。它不证明分区可迁移：S 同时参与扫描、候选接受及配方选择，候选和祖先节点互相重叠。这些计数不是独立重复试验；子模型探针对照的是不可变全局根，不能直接代替递归父模型或实际路由的增益。

来源：[模型探针](/tmp/ipcch-signal-probe-20261005/summary.md)、[逐子模型数据](/tmp/ipcch-signal-probe-20261005/per-child.csv)、[根层同键核对](/tmp/ipcch-stage1-root-crosscheck-20261005.json)、[F/S 日历与正则化](/tmp/ipcch-split-reg-probe-20261005/summary.json)。

## 三、Stage3 要分开看局部效力、验证支持和覆盖

### 3.1 真正拟合的历史局部模型

主期历史验证记录按 `(H, region, U, admin)` 去重后，共 551 个区域日期单元、40,286 行；其中 **517 个单元、37,992 行有真实局部拟合**。另 34 个单元、2,294 行只是全局回退，不能计为局部模型的零增益。

517 个真实局部单元的 F1 增益分布为：大于 0.01 有 67 个，小幅正增益 17 个，零 297 个，负 106 个，未定义 30 个。唯一配对行跨 H 池化后，global F1 为 0.802677、local 为 0.804874，差 **+0.002196**；原始 q3 MSE 则从 0.011626 升至 0.011762。这是历史验证的描述性结果，不是最终部署收益，也不是“局部多数更差”的总体证据。F1 相同不表示所有标签逐行相同。

| 局部训练键数 | 区域日期单元 | 配对行 | 验证危机比例 | 池化 local−global F1 |
| --- | ---: | ---: | ---: | ---: |
| 500–999 | 237 | 7,748 | 49.30% | -0.003389 |
| 1,000–1,999 | 169 | 15,886 | 36.61% | -0.000298 |
| ≥2,000 | 111 | 14,358 | 28.88% | +0.009282 |

这张表不能解释为样本量的因果效应。H6 的 r01 有 4,078–4,402 个训练键，区域池化 ΔF1 仍为 −0.01995。同一 H/region 内，高于与低于训练量中位数的比较，更好/更差/相同为 14/15/2；但 27/31 组的最大/最小训练量比小于 1.5，变化有限，也不能排除更大幅度增加训练支持的作用。

### 3.2 Gate：不要把被拒子集当作总体

全部 973 条 gate（主期 849、补充期 124）已逐条复算支持、混淆计数、精确 F1 和当前路由，零不一致。

| 主期 gate 范围 | 数量 | ΔF1 > .01 | 0 < ΔF1 ≤ .01 | 零 | 负 | 未定义 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 全部 | 849 | 145 | 76 | 315 | 295 | 18 |
| 历史验证支持合格 | 265 | 43 | 31 | 35 | 156 | 0 |
| 历史验证支持合格且当前有预测键 | 194 | 26 | 25 | 25 | 118 | 0 |

在历史验证支持合格的窗口中，156/265 为负；有当前预测键时为 118/194。这支持保留保守 gate，不能把未采用局部全部解释为门槛功效不足。另一方面，145 个高于 .01 的窗口中有 102 个因历史支持不足被拒，其中 49 个涉及 3,099 个当前预测键；既没有它们的当前局部反事实，也没有证明历史高增益只是噪声，不能宣称放行必然有益或必然无益。

这些窗口会复用历史记录：主期最多七次，补充期内最多四次，不能作独立显著性计数。训练行数与历史验证的行数、地区数、类别数、日期数及成功局部拟合日期数是不同的支持维度。

### 3.3 当前预测的覆盖损失

| 主期路线/原因 | 含 H 的预测键数 | 占全部 64,741 键 |
| --- | ---: | ---: |
| 地图外，使用全局 | 27,506 | 42.49% |
| 地图内，历史验证支持不合格 | 24,759 | 38.24% |
| 地图内，历史增益未过门槛 | 10,688 | 16.51% |
| 实际采用局部 | 1,788 | 2.76% |

地图内的 37,235 键中，66.50% 被历史支持拒绝、28.70% 被增益门槛拒绝，4.80% 使用局部。支持拒绝的 24,759 键中，16,128 涉及成功局部拟合日期不足，其中 15,160 同时涉及验证日期不足；原因重叠，不能相加，也不能全部归为“没有观测日期”。当前训练支持未记账的分支，不等于当前训练不合格。

分区更细可能更同质，但训练与验证支持更弱；分区更粗可能增加可评估性，却稀释异质性。已有证据确立了这项设计约束，没有识别出唯一根因。来源：[综合与解释边界](/tmp/ipcch-stage3-support-synthesis-20261005.md)、[历史局部支持](/tmp/ipcch-stage3-history-support-20261005/summary.md)、[gate 与当前覆盖](/tmp/ipcch-stage3-gate-population-20261005/report.md)。

## 四、残差均值扫描：可以提出候选，尚不能称为修复

原提议是用全局 q3 残差 `r_i`，定义区域 `R` 的残差和 `S_R`、记录数 `n_R`，取常数修正：

`δ_R = S_R / (n_R + λ)`

以及二分 `R → A,B` 的分数：

`gain = S_A²/(n_A+λ) + S_B²/(n_B+λ) − S_R²/(n_R+λ)`。

λ=0 时是组间平方和形式；λ>0 对应带 L2 惩罚的常数修正收益，与平方误差 XGB 的叶分数同形（忽略共同尺度和其他分裂惩罚）。它可表述为空间约束的残差回归树或区域校准准则，不应包装为新数学。普通 XGB 的特征阈值与地理成员划分的搜索空间仍不同。

需要保留三项限制：

1. **水平偏差不是全部异质性。** 区域平均残差可以为零，但特征—目标斜率不同；均值扫描会漏掉这类条件信号。它也不等于把所有份额无条件拉回全局。
2. **真实局部树不等于一次均值修正。** 现有局部模型在 F 上逐树继续训练，并有 `alpha=1`、`eta=.05`、叶级支持约束。λ=20 在区域尺度的收缩中位数约 1.36%，但在获胜配方局部 q3 树的叶尺度，中位数约 8.23%、最大 50%。10,101 片叶中 2,255 个零权重只是观察，不能据此断言放松正则化会提高测试表现。
3. **同一 S 上改进不能证明迁移。** 用 S 估计 δ 本身就是校准拟合；所得 F1 不是该地图的一般 oracle 上界，也不能用任意 .01 门槛判死刑。借鉴 Causal Tree 的拟合/评估分离可以作为设计原则，但复用 S 不具备 honest 独立性，本任务也没有因果处理效应识别。

因此残差扫描目前暂缓：未被证明优于现扫描，也未被证明一定无用。“扫描不是瓶颈”与“换统计量能修好分区”都超出当前证据。

## 五、K-means 初始化 → 区域 boosting → 地区交换

用户提出的方向是先给定初始分区，再交替更新模型与地区归属。值得讨论的核心不是 K-means 本身，而是：**在相同 K 和支持约束下，按模型适配程度交换地区，是否比固定初始分区获得更可迁移的增量？**

一个最小候选流程如下，尚未决定实施：

1. **初始化**：只设少量由真实训练/验证支持允许的较粗 K。按空间坐标聚类与按环境、经济特征聚类含义不同；前者需要合适的距离表示，普通经纬度 K-means 也不保证实际邻接图连通。若以连通为要求，应在初始可行分区和后续交换中都明确检查。
2. **局部拟合**：每个区域从同一份全局模型的独立副本继续 boosting，保留四份额回归、投影及 20% 解码。每轮重拟合时不把之前交换轮次或祖先区域的增量不断累积。
3. **交换提议**：按完整地区移动，优先考察边界地区移至相邻区域，保留源/目标连通性及支持下限。不是看到某地区残差大就搬走，而是在同一批可用于选择的记录上比较两个固定模型：`Δ_i(a→b) = L_i(f_a) − L_i(f_b)`。没有目标模型对该地区的同键预测，就没有交换收益证据。
4. **重拟合与接受**：连续损失差可生成候选，但交换后两侧训练集与模型都会改变，固定模型下的收益不保证保留。需重拟合并重新评价一批交换后的整体投影标签 F1；F1 对地区不可加，不能直接相加地区 F1 或只优化原始 q3。

K 控制粒度和支持，不宜只按初始化的紧凑程度选择，也不宜在已看过的测试期大范围搜索。首先比较“固定 K 初始化”与“同 K 加交换”，才能识别交换是否有价值；多个 K、边权学习、传播和自动分裂合并同时加入，会难以分辨收益来源。

更重要的限制仍是选择数据复用。反复在 S 上交换会增加适应性过拟合；把原 Stage1/Stage2 的候选生成—接受再命名一遍不会增加独立证据。IPCCH 日期稀疏，不宜未经可行性检查就再硬拆出大段验证集。若设计部署一致的历史滚动评估，地图生成、配方和每次预测都必须只用当时允许的数据；已观察过的 2025–2026 只能支持探索，最终迁移主张需要未用于选择的证据。

## 六、两轮敏感性检查怎样改变优先级？

| 已完成检查 | 观察 | 能收缩的解释 |
| --- | --- | --- |
| 固定地图/配方，36 月改全历史；11 个 H/日期组合，不应用 gate | 共同局部支持的 14,400 键上，local−global F1 从 +0.000386 变为 −0.007819 | “加回旧历史就能恢复局部收益”缺乏支持；不能据此选择最优窗口或代替完整部署比较。 |
| Stage1 延至 2024 年，重学地图与配方；O≥2025-01，完整 gate | 学习地区 3,264→4,058；H1/3/6/12 的 Geo−pooled F1 为 0/−0.000490/−0.000505/0 | 增加近期开发数据与覆盖仍未恢复增量。H12 整体 F1 提升同时发生在 pooled，不能归为地理收益。 |

这两项结果降低了只改时间窗口的优先级，但没有直接比较两种分区算法，也没有隔离正则化的作用。SMOTE 或重复行无法增加独立日期与地区，不能据此解决历史 gate 的支持缺口；目前也没有证据支持先引入学习边权或 GNN。

后续若继续，最值得讨论的是三个可区分的问题：

- **区域粒度能否兼顾效力和可采用性？** 同时报支持合格覆盖、局部相对 pooled 的效果、全队列最终收益；不以放宽 gate 代替改善支持。
- **地区交换是否胜过固定初始分区？** 固定 K、配方、预算与评价键，保留 pooled 和当前地图参考，只改变交换步骤；若只在参与交换选择的 S 上提高，仍不能称为迁移改善。
- **改进来自分区还是局部学习器？** 地图与局部正则化分别改变才有归因意义。现有叶权重观察可支持提出假设，尚不支持直接调参结论。

这些是未来讨论入口，不是新增实验清单的批准。当前可以报告的结论是：开发期确有局部增益，部署期受到覆盖、支持及历史局部效果共同限制；更多历史和更晚的开发切分没有解决问题，下一步需要直接检验分区与实际局部拟合的匹配程度。
