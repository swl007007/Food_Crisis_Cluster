# Baseline Workstream

## Status

Reserved for a future approved baseline audit. No scripts, copied inputs,
generated artifacts, or model results are present.

## Required audit dimensions

- forecast-origin availability of every feature;
- temporal train/validation/test generalization by horizon;
- spatial generalization and Ethiopia admin-level support;
- pooled versus partitioned model complexity;
- branch and cluster sample sizes;
- class imbalance, decision thresholds, and calibration;
- feature stability and sensitivity to suspicious feature families;
- reproducibility across seeds where stochasticity affects conclusions;
- consistency between configured and effective temporal windows.

The audit design and success criteria must be approved before any run. CDS work
does not begin until a reviewed Ethiopia baseline is frozen.
