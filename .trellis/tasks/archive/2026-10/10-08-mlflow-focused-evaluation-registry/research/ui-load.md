## Native options and scope tradeoffs (no scope selected)

| Option | What it can reduce | Cost / boundary |
|---|---|---|
| Native filter by family/arm/horizon plus focused columns/charts; avoid loading extra pages | Server filters reduce returned rows; focused columns/charts reduce visible clutter | Full metrics remain on each selected run. Excluding only parents saved little (4.67 to 4.61 MB). Actual browser improvement unmeasured. |
| Add a compact evaluation experiment with selected metrics, links to current child/parent run IDs and existing source artifacts | Reduces metrics per returned run and available column-name set; preserves historical run IDs and retained reports | Additional lightweight comparison records and importer/profile logic; user must decide which periods/cohorts/scores and whether all arms/seeds belong. Keep raw panels/provenance/NA entries accessible via current artifacts. |
| Rebuild evaluation records in the current experiment with compact metrics, retain old records under a documented historical policy | Reduces active metric density if old runs are actually removed from the active search scope | New run IDs, backlinks and history migration policy; must preserve parent/artifact lineage and avoid duplicates in default UI. Requires explicit implementation/migration scope. |
| In-place metric deletion / direct SQLite cleanup | Could physically shrink existing records | **No native delete-run-metric API** was found in installed MlflowClient or MlflowService descriptor. Direct SQL bypasses MLflow/importer contracts. Current `reconcile_family` explicitly refuses changed metrics (`import_runs.py:680–681`); current importer fingerprints also change when metrics change (`217–230`, existing-child conflict `537–538`). This is not a supported reconcile toggle. |

A purely illustrative whitelist retaining direct panel n plus nine scores for E_all/E_persist/local_eligible/local_persist_matched across period prefixes retained **4,808 entries / 140 unique names**, versus 20,528 / 1,528. Regex used: `^[^.]+\.(?:E_all|E_persist|local_eligible|local_persist_matched)\.(?:binary\.(?:accuracy|precision|recall|f1|f2)|four_class\.(?:accuracy|macro_f1)|q3_r2_(?:projected|raw)|n)$`. This omits contrasts, gated local subpanels and selected-date/window cohorts; **not an approved metric contract**. No records were created.

Scientific comparison boundary must survive any compact design: same metric name is insufficient for cohort equivalence; key digests are `cohort_keys.{period}.{cohort}` (`IPCCHMLflow/README.md:64–70`, extractor `cohort_tag:163–170`). Keep period/cohort semantics and NA reasons; never flatten incomparable full-period and selected-date values into one unlabeled score.
